# humanize-korean

주어진 한국어 글을 원래 뜻과 정보는 그대로 두고, 한국어 화자가 직접 쓴 것처럼 읽히게 다시 쓴다.

## 입력

- 인자로 받은 텍스트, 또는 사용자가 지정한 파일 경로의 내용.
- 아무것도 없으면 다듬을 글을 붙여넣어 달라고 한 줄로 요청한다.

## 작업 순서

1. **용도와 어조 파악**: 블로그, 업무 메일, 메신저, 자기소개서, 보고서 등 글의 용도를 추정한다. 원문의 높임 수준(합쇼체/해요체/해체/평서문)을 유지한다. 판단이 안 서면 원문 어조를 따른다.
2. **아래 패턴을 찾아 고친다.**
3. **결과 출력**: 다듬은 글 전체를 먼저 보여준다. 그 아래에 주요 변경점을 3~5개 짧게 덧붙인다. 사용자가 "결과만"이라고 하면 변경점은 생략한다. 파일을 받았으면 사용자가 원할 때만 파일을 수정한다.

## 고칠 패턴

### 번역투
- `~에 대해`, `~에 있어서`, `~를 통해`, `~로 인해`의 남발 → 조사나 동사로 풀어 쓴다.
  - "이 문제에 대해 논의를 진행했습니다" → "이 문제를 논의했습니다"
- `~하는 것이 중요합니다`, `~할 필요가 있습니다` → "~해야 합니다", "~하면 좋습니다"
- 피동 남용(`~되어지다`, `~에 의해 ~되다`) → 능동문으로.
- `그것은`, `이것은`, `그들은` 같은 대명사 주어 → 생략하거나 구체적인 명사로.
- `가지다`, `갖다`의 영어식 사용("회의를 가졌다") → "회의를 했다"
- 명사형 나열(`~의 ~의 ~`) → 동사 중심 문장으로.

### AI 특유의 말버릇
- 서두의 상투어: "물론입니다!", "좋은 질문입니다", "~에 대해 알아보겠습니다" → 삭제.
- 결론부 상투어: "결론적으로", "요약하자면", "이처럼 ~는 매우 중요합니다", "도움이 되셨길 바랍니다" → 삭제하거나 구체적인 마무리로.
- 과장된 수식어: "매우", "정말", "다양한", "효과적인", "핵심적인", "혁신적인" 반복 → 줄이고 구체적 사실로 대체.
- 문장마다 붙는 접속사: "또한", "더불어", "뿐만 아니라", "따라서", "하지만" → 필요한 곳에만.
- 항상 셋씩 묶는 나열("A, B, 그리고 C") → 실제 필요한 개수만.
- 굵은 글씨·불릿·소제목 과다 → 원문이 문서 형식이 아니면 문단으로 풀어 쓴다.
- 영어식 쌍점 구조("핵심: ~", "결과: ~") → 문장으로.

### 리듬과 문장
- 길이와 구조가 똑같은 문장이 반복되면 짧은 문장과 긴 문장을 섞는다.
- `~습니다.`로만 끝나는 단조로운 종결 → 같은 높임 수준 안에서 변화를 준다("~죠", "~거든요" 등은 해요체일 때만).
- 한 문장에 정보가 너무 많으면 나누고, 너무 잘게 쪼개졌으면 합친다.
- 불필요한 쉼표를 뺀다.

### 단어 선택
- 한자어·외래어가 굳이 필요 없으면 쉬운 우리말로("활용하다" → "쓰다", "진행하다" → 구체적 동사).
- 같은 단어를 가까이서 반복하지 않는다.

## 지켜야 할 것

- 사실, 수치, 고유명사, 인용, 전문용어는 바꾸지 않는다.
- 내용을 새로 지어내거나 의견을 추가하지 않는다. 덜어내는 건 군더더기에 한한다.
- 원문의 높임 수준과 화자 관점을 유지한다.
- 일부러 맞춤법을 틀리거나 신조어·이모티콘을 넣어 "사람인 척"하지 않는다. 목표는 자연스러움이지 흉내가 아니다.
- 사람이 쓴 것처럼 꾸며 탐지 도구를 피하는 것 자체가 목적인 부정행위(과제 대필 은폐 등)가 명백하면 그 점을 짚는다.

## 예시

**원문**
> 물론입니다! 효과적인 시간 관리에 대해 알아보겠습니다. 시간 관리는 현대인에게 있어서 매우 중요한 요소입니다. 또한, 이를 통해 생산성을 향상시키는 것이 가능합니다. 결론적으로, 체계적인 계획을 세우는 것이 중요합니다.

**수정**
> 시간 관리를 잘하면 같은 시간에 더 많은 일을 끝낼 수 있습니다. 시작은 하루 계획을 미리 세워 두는 것입니다.
